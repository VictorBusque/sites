01 / Start at the user

The “dish” is really a steerable radio.

Open the terminal and you do not find a little motor that constantly points a conventional dish. The user antenna is a phased array: many small radiating elements work together. By changing the relative phase of those elements, the terminal makes the combined electromagnetic wave add up strongly in one direction and cancel more strongly elsewhere.

Δφ across elements → different wavefront direction → beam can move without mechanically rotating the antenna.

02 / The first hop

Now the beam reaches a moving satellite.

The terminal is not locked to one spacecraft forever. It can see multiple satellites while they cross the sky. A narrow RF beam is formed toward one satellite, while the network prepares the next link before the current one becomes a poor choice.

Earth → phased-array terminal → Ku-band link → satellite payload.

03 / Handoff

Then the network moves the link.

LEO satellites move quickly across the sky. So Starlink constantly evaluates which satellite offers the best usable path — including obstruction and link quality — and performs a beam / satellite handoff while keeping the session alive.

Satellite A weakening → Satellite B rising → schedule B → switch RF link → continue packets.

04 / Space-to-space

Inside the constellation, lasers take over.

Modern Starlink spacecraft can pass traffic directly between satellites using optical inter-satellite links. A laser terminal points at a neighboring spacecraft, acquires the link, and sends data through free space instead of immediately dropping every packet to Earth.

RF from user → satellite → optical ISL → satellite → optical ISL → …

05 / Back to Earth

A gateway is where space meets fiber.

Eventually the packet has to leave the satellite network and enter terrestrial infrastructure. A Starlink gateway communicates with the spacecraft over RF, while its terrestrial side connects into Starlink’s ground network and internet Points of Presence. The gateway is the bridge between the orbital fabric and the fiber world.

Satellite RF downlink → gateway earth station → terrestrial network / PoP → internet.

06 / Routing

The path is chosen in real time.

There is no fixed “Starlink route.” The usable topology changes as satellites move, gateways become available, links congest, and obstructions change. Traffic can stay in space for several hops, or drop to Earth earlier when that is the shorter or better path.

Choose a usable path across a moving graph — not a permanent wire.

07 / The whole system

So the dish is only the front door.

What makes Starlink unusual is the composition: a steerable user terminal, a moving constellation of LEO routers, high-capacity optical links between spacecraft, gateways and terrestrial PoPs. From the user’s perspective it looks like Wi-Fi. Underneath, it behaves much more like a distributed network whose routers happen to be flying around Earth.

Laptop → terminal → RF → satellite → laser mesh / gateway → internet → reverse path → terminal → laptop.

Why the architecture matters

LEO reduces propagation distance. Phased arrays make links steerable without large mechanical antennas. Optical inter-satellite links let traffic cross oceans without touching terrestrial fiber. Gateways connect the orbital network back to the internet. Put together, those pieces create a network that trades fixed infrastructure for a moving, redundant graph.

Engineering notes & sources
Starlink publishes that its satellites use advanced phased-array antennas and optical inter-satellite links; its public technology page describes V2-era spacecraft with three optical links up to 200 Gbps, while its V3 announcement describes six 400 Gbps optical links and next-generation beamforming hardware. Starlink also describes automatic satellite switching and real-time obstruction-aware behavior.
