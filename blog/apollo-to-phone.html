01 / The baseline

The computer that flew to the Moon was already an engineering miracle.

The Apollo Guidance Computer was not a modern CPU with “less power.” It was a radically different machine optimized to do one job: guidance, navigation and control, in real time, under brutal mass, power and reliability constraints.

Block II AGC: 15 data bits + parity · 36,864 fixed-memory words · 2,048 erasable-memory words · 34 normal instructions · 1.024 MHz internal computer clock.

A whole spacecraft, concentrated into a tiny memory.

The AGC's program lived mostly in fixed core-rope memory. Variables lived in a tiny erasable memory. The machine had to reuse memory addresses aggressively because there simply wasn't much of it.

“More powerful” begins as a misleading question.

Apollo and the iPhone do not execute the same instruction set, benchmark the same way, or solve the same workload. The useful story is the convergence of several curves: frequency, transistor density, memory, parallelism and specialization.

02 / Silicon accelerates

Once the processor itself became a mass-manufactured integrated circuit, the machine stopped being a spacecraft component and started becoming a platform.

03 / A scale you can see

Memory makes the change physically legible.

Clock speed and benchmark scores are not comparable across these machines. Working memory is more concrete: the Apollo Guidance Computer had about 3.75 KiB of erasable data memory; the original iPhone had 128 MB; the iPhone 17 Pro Max is reported with roughly 12 GB.

This is a logarithmic scale, not a race.

Each vertical step doubles working memory. The distance between the markers therefore represents a real multiplication, rather than an illustrative change in the size of a device.

The remarkable part wasn't the first smartphone. It was what came next.

Once mobile silicon adopted multi-core CPUs, large caches, programmable GPUs and neural accelerators, the “phone” became a heterogeneous computer: different engines, each built for a different kind of work.

04 / Heterogeneous compute

Raw speed was no longer the whole game.

Modern phone silicon does many jobs at once. CPU cores handle general logic. GPUs handle massively parallel graphics and math. Neural engines handle matrix-heavy inference. Media blocks encode and decode video without burning the general-purpose cores.

One chip. Many kinds of computers.

The A17 Pro, introduced in 2023, reached 19 billion transistors and a Neural Engine rated at up to 35 trillion operations per second. The A19 Pro keeps the 16-core Neural Engine architecture while adding neural accelerators inside every GPU core.

The takeaway

We didn't make the computer on the Moon slightly faster.

We changed what “a computer” could afford to contain. The Apollo Guidance Computer had to ration memory, arithmetic and power. Modern mobile silicon spends that budget on parallel engines, caches, graphics, machine learning, video, sensors and an operating system—all inside a device that weighs less than a soda can.

What really changed

Transistor density made more logic economically possible. Better process technology made that logic smaller and more energy-efficient. Architecture learned to exploit parallelism. Specialized blocks took work away from the general-purpose CPU. Software grew into the machine instead of being squeezed into it.

What did not change

The fundamental problem is still the same: turn information into actions under constraints. Apollo did it with fixed-point arithmetic, core-rope memory and hand-optimized software. The iPhone does it with billions of transistors, heterogeneous acceleration and an enormous software stack.
